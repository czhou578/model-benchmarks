## The config

All three runs used the same server command. Run C adds `--no-enable-prefix-caching`.

| Setting | Value |
|---|---|
| Weights | NVFP4 MLP weights, FP8 attention (NVIDIA ModelOpt) |
| KV cache | `--kv-cache-memory-bytes 16G` (the KV pin), `--kv-cache-dtype fp8_e4m3`, `--gpu-memory-utilization 0.45` |
| Limits | `--max-model-len 262144`, `--max-num-seqs 16`, `--max-num-batched-tokens 8192` |
| Prefix caching | Off. Run C sets `--no-enable-prefix-caching`. Runs A and B set no flag. The `model_config.yml` of run C says that vLLM 0.25.1 kept it off. |
| Other flags | `--attention-backend flashinfer`, `--enable-chunked-prefill`, `--async-scheduling`, `--enable-per-request-metrics`, `--generation-config vllm`, `--load-format fastsafetensors` |
| Parsers | `--reasoning-parser qwen3`, `--tool-call-parser qwen3_coder` |
| Spec decoding | None in the main server. For the spec-on server, `--compare-spec` adds `speculative_config`: `{"method":"mtp","num_speculative_tokens":3}` (MTP, K=3). |
| Tool calling | `tool_calling_max_tokens: 4096`, temperature 0 |

Source: `resolved_server.json`, `resolved_server_spec_enabled.json`, and `model_config.yml`.

## Caveats

- The FLOP analysis gives `estimate_status: unsupported` for all three runs. The estimator knows only the Qwen3.6-35B-A3B dimensions.
- Runs A and B predate PRs #67-#69. In these runs, the server TTFT split counted the queue time two times, and the energy used the old method. Run A also sent one shared prompt to every concurrency request. Do not compare the TTFT split, the energy, or the concurrency numbers of run A with run C.
- In run C, the task `schema_title_max_length_fail` failed on the old 120 s request timeout (`Read timed out. (read timeout=120)`). PR #73 later raised the default timeout to 600 s.
- With MTP, one stream event carries several tokens. The per-event peak, min, and median rates of the MTP-on server are not valid. Use the mean only. For example, the run C peak at 512 tokens is 9.59, below the mean of 24.47.
- With 85 tool tasks, the 95% confidence interval of a pass rate is about ±10 points. The difference between A and C (2 tasks) is inside this noise.
- Run A and run C differ in the vLLM version, the torch version, and the prefix-caching flag.
